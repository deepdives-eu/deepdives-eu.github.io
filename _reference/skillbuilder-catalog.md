# AWS Skill Builder catalog for deepdives.eu course pages

This file is a working reference for maintainers and is not published on the site (Jekyll ignores folders starting with an underscore).
It collects AWS Skill Builder content that has been verified by opening the page in a browser, grouped by type. Reuse entries on course pages and add new ones as further courses are covered.

Skill Builder is a JavaScript application, so plain HTTP checks cannot tell a real page from a missing one. Verify a link by loading it in a browser and reading the title; a missing item shows "Page not found".

Columns: title and link, access (free, subscription, classroom event), related course pages, verified date.
